# 🏫 우리 반 관리 콘솔 (class-manager)

담임 선생님을 위한 **설치 없는 웹 기반 학급 관리 콘솔**입니다.
[2026203 관리 콘솔](https://polarbears78.github.io/2026203/admin.html)과 같은 형식으로 만들어졌으며,
학교·반 정보를 하드코딩하지 않아 **어느 선생님이든 그대로 가져다 쓸 수 있는 배포용**입니다.

## 페이지 구성

| 페이지 | 기능 |
|---|---|
| `index.html` **대시보드** | 등록 학생·상담·시험 요약, 관리 메뉴 타일, 최근 상담, 학급 이름 설정, 데이터 백업·복원 |
| `counsel.html` **학생·상담** | 학생별 카드(연락처·가정환경·메모), 상담 기록, 상담카드 엑셀(.xlsx) 불러오기, 성적 레이더·추이, PDF 저장 |
| `grades.html` **성적** | 시험별 점수 입력, 과목별 분석, 총점·석차, 개인 vs 반 평균 비교, 나이스 엑셀·CSV 불러오기 |
| `report.html` **생기부 분석** | 생기부(PDF·텍스트)를 불러와 **학교에 설치한 AI 서버**로 학부모 상담 자료 초안 생성, 인쇄·상담 기록 저장 |
| `handout.html` **학부모 안내문** | 상담 때 학부모께 드리는 **A4 한 장 유인물** — 강점 · 성적 그래프 · 가정에서 도와주실 일 · 담임 한마디, 미리보며 편집 후 인쇄 |
| `upload.html` **생기부 업로드** 🚧 | 생기부를 올리고 학생 인식 결과를 확인하는 화면 — **구조 확인용 뼈대**(아직 동작 안 함) |
| `result.html` **분석 결과** 🚧 | 학생·목적·영역을 고르고 상담 자료를 보는 화면 — **구조 확인용 뼈대**(아직 동작 안 함) |
| `manage.html` **학급 도구** | 학생 명단, 발표자 뽑기, 모둠 편성, 청소 당번, 월별 자리 배치(+PDF 인쇄) |
| `guide.html` **학급 안내** | 급훈·운영 방향·학급 규칙·상담 안내·시간표 — 클릭해서 바로 편집, 인쇄 게시용 |
| 상담 빠른 입력 💬 | 대시보드 우측 하단 채팅 버튼 — 문장으로 적으면 이름·날짜·영역을 자동 인식해 상담 카드에 저장 |

## 사용 방법

1. 저장소 파일을 통째로 내려받아 `index.html`을 브라우저로 열거나,
2. GitHub Pages 주소를 즐겨찾기에 추가해 사용합니다.

첫 화면(대시보드)의 **학급 이름 설정**에 반 이름(예: `2학년 3반`)을 저장하면
모든 페이지 상단과 자리 배치표 인쇄물에 반영됩니다.

## 생기부 분석 · 학부모 상담 자료

`report.html`은 생기부를 읽고 학부모 상담용 초안(강점 / 함께 지켜볼 점 / 학부모께 드릴 말씀 /
예상 질문과 답변 / 가정에서 도와주실 일)을 만들어 줍니다.

분석에는 **학교에 설치한 AI 서버**만 사용합니다. 외부 클라우드 AI는 쓰지 않으며,
생기부 내용은 교내망 안에서만 오갑니다. 설치 방법은 [젯슨 설치 가이드](JETSON.md)를 보세요.

- 지원 서버: **Ollama**(`/api/chat`), **OpenAI 호환**(`/v1/chat/completions` — llama.cpp·vLLM 등). 규격은 자동으로 가려냅니다.
- 불러오기: 생기부 **PDF**·**텍스트(.txt)** 파일 또는 **붙여넣기**. 여러 학생이 한 파일에 있어도 자동으로 나눕니다.
- [성적] 페이지의 점수·반평균과 [학생·상담] 페이지의 상담 기록을 함께 넣어 분석할 수 있습니다.
- 만들어진 초안은 인쇄(PDF 저장)하거나 상담 기록으로 저장할 수 있습니다.

> ⚠️ AI가 만든 글은 **초안**입니다. 사실 관계와 표현을 담임 선생님이 반드시 확인·수정한 뒤 사용해 주세요.

### 상담에 쓰는 두 가지 인쇄물

| | 누가 보나 | 내용 |
|---|---|---|
| **상담 자료** (`report.html`) | 담임 선생님 | 상담 전에 읽는 준비 자료. 강점·지켜볼 점·예상 질문과 답변까지 8개 항목 |
| **학부모 안내문** (`handout.html`) | 학부모 | 상담 때 드리는 A4 한 장. 강점 · 성적 그래프 · 가정에서 도와주실 일 |

안내문은 상담 자료 초안에서 **강점**과 **가정에서 도와주실 일**을 자동으로 끌어와 채웁니다
([생기부 분석] 결과에서 `📄 학부모 안내문 만들기`를 누르면 바로 넘어갑니다).
성적 그래프는 [성적] 페이지에 입력한 점수와 반 평균으로 그려집니다.
학교 이름·학년도·담임 성명·연락처는 한 번 저장해 두면 모든 안내문에 자동으로 들어갑니다.
생기부나 AI 서버 없이 **직접 타이핑해서 쓸 수도 있습니다.**

### 화면 흐름 (정리 중)

지금은 업로드·분석·결과가 `report.html` 한 페이지에 모두 들어 있습니다.
이걸 아래처럼 두 화면으로 나누려고 하며, **뼈대만 먼저** 만들어 두었습니다.

```
upload.html          result.html               handout.html
생기부 업로드     →     분석 결과          →     학부모 안내문
  서버 연결             학생·목적·영역 선택        A4 한 장 유인물
  파일·붙여넣기          상담 자료 초안
  학생 인식 확인         복사·인쇄·기록 저장
```

두 뼈대 화면은 배치만 보여 주며 아직 동작하지 않습니다.
**실제로 쓰는 것은 `report.html`(생기부 분석)** 이고, 구조가 확정되면 그 기능을 두 화면으로 옮긴 뒤
`report.html`을 정리할 예정입니다.

## 다른 선생님께 배포하기

- **링크로 배포 (권장)**: 이 저장소에서 GitHub Pages를 켜면 (Settings → Pages → Branch: `main`)
  `https://<계정명>.github.io/class-manager/` 주소를 그대로 공유하면 됩니다.
- **파일로 배포**: 저장소 ZIP을 전달해도 됩니다. 단, 엑셀 불러오기 기능은 인터넷 연결이 있어야
  동작합니다(파서 라이브러리를 CDN에서 불러옴 — 파일 내용 자체는 브라우저 밖으로 나가지 않음).
- 어떤 방식이든 **입력한 데이터는 각자 브라우저(localStorage)에만 저장**되므로,
  링크나 파일을 공유해도 내 학급 데이터는 함께 전달되지 않습니다.

## 개인정보 안내

- 학생 명단·상담 기록·성적은 서버로 전송되지 않고 사용 중인 브라우저에만 저장됩니다.
- 엑셀·CSV 파일도 브라우저 안에서만 읽히며 어디에도 업로드되지 않습니다.
- **생기부 분석**은 예외적으로 내용을 서버에 보냅니다. 단, 보내는 곳은 선생님이 직접 입력한
  **학교 안의 AI 서버뿐**이며 인터넷으로 나가지 않습니다. 생기부 원문은 저장되지 않고(새로고침하면 사라짐),
  주민등록번호·연락처·주소·이메일은 전송 전에 항상 지워집니다. 이름도 선택으로 가릴 수 있고,
  전송 전에 **실제로 보낼 내용을 직접 확인**할 수 있습니다.
- 공용 컴퓨터에서 사용한 경우 대시보드의 **전체 초기화**를 눌러 주세요.
- 백업 JSON 파일에는 학생 개인정보가 포함되므로 개인 저장 공간에만 보관하세요.
