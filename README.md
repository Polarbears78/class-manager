# 🏫 학급 관리 페이지 (class-manager)

담임 선생님을 위한 **설치 없는 웹 기반 학급 관리 도구**입니다.
Notion으로 운영하던 학급관리 페이지(학급 안내문 · 명렬표 · 학생 카드 · 1인 1역)를 참고하여,
누구나 브라우저만 있으면 바로 쓸 수 있는 단일 HTML 파일로 만든 초안입니다.

## 주요 기능

| 탭 | 기능 |
|---|---|
| **학급 안내** | 급훈, 학급 운영 방향, 학급 규칙, 담임 연락처·상담 안내 — 화면에서 바로 클릭해 수정 |
| **시간표** | 주간 시간표 편집, 인쇄(Ctrl+P)하면 교실 게시용으로 활용 |
| **학생 관리** | 명렬표 + 학생 카드(연락처, 특이사항 태그, 알레르기, 상담 메모), 검색, CSV 내보내기 |
| **1인 1역** | 역할 분담표 (출결·우유·생일·보건 등 기본 역할 포함) |
| **학급 일지** | 날짜별 전달사항·특이사항·상담 메모 기록 |
| **데이터 관리** | JSON 백업/복원, 전체 초기화 |

## 사용 방법

1. `index.html` 파일을 다운로드해서 더블클릭으로 열거나,
2. GitHub Pages 주소를 브라우저 즐겨찾기에 추가해서 사용합니다.

별도 로그인이나 설치가 필요 없습니다.

## 다른 선생님께 배포하기

- **파일로 배포**: `index.html` 파일 하나만 메신저·이메일로 전달하면 됩니다.
- **링크로 배포**: 이 저장소에서 GitHub Pages를 켜면 (Settings → Pages → Branch: `main`)
  `https://<계정명>.github.io/class-manager/` 주소를 공유할 수 있습니다.
- 어떤 방식이든 **입력한 데이터는 각자 브라우저(localStorage)에만 저장**되므로,
  링크나 파일을 공유해도 내 학급 데이터는 함께 전달되지 않습니다.

## 개인정보 안내

- 학생 정보는 서버로 전송되지 않고 사용 중인 브라우저에만 저장됩니다.
- 공용 컴퓨터에서 사용한 경우 [데이터 관리] 탭에서 **전체 초기화**를 해 주세요.
- 백업 JSON/CSV 파일에는 학생 개인정보가 포함되므로 개인 저장 공간에만 보관하세요.
