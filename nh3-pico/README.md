# 🧪 Pico 2 W 암모니아(NH₃) 측정기

MQ 계열 금속산화물 가스 센서 모듈(3핀: VCC · OUT · GND)을 Raspberry Pi **Pico 2 W**에 연결해
NH₃ 농도를 측정하고, **Pico 플래시에 CSV로 저장**한 뒤 **휴대폰/PC 브라우저에서 내려받는** 펌웨어입니다.
내려받은 CSV는 콘솔의 [`nh3.html`](../nh3.html) 분석 페이지에 업로드해 그래프·통계로 봅니다.

| 파일 | 역할 |
|---|---|
| `main.py` | 측정 · 저장 · Wi-Fi 웹 서버 (전원 인가 시 자동 실행) |
| `config.py` | Wi-Fi, 배선, 센서 종류, 기록 간격 설정 |
| `index.html` | Pico가 제공하는 제어 화면 (실시간 값 · 표시 · 파일 다운로드 · 교정) |

## 1. 배선

> ⚠️ 모듈 OUT은 최대 5 V까지 올라갑니다. Pico ADC 허용 전압은 3.3 V이므로 **반드시 분압**하세요.

```
모듈 VCC ── Pico VBUS (핀 40)   ※ USB로 전원을 공급할 때 5 V
모듈 GND ── Pico GND  (핀 38)
모듈 OUT ── 10 kΩ ──┬── Pico GP26 / ADC0 (핀 31)
                    10 kΩ
                    │
                   GND
```

- MQ 센서 히터는 약 150 mA를 소모합니다. Pico 3V3 핀이 아닌 **VBUS(5 V)** 에 연결하세요.
- 사진의 모듈은 라벨에 모델명이 없으므로 **모듈 앞면의 센서 각인(MQ-137 / MQ-135 등)** 을 확인해 `config.py`의 `SENSOR_MODEL`을 맞추세요.
- 모듈 뒷면 SMD 저항 표기로 부하저항 RL을 확인해 `RL_KOHM`에 입력합니다 (`102`=1 kΩ, `472`=4.7 kΩ, `103`=10 kΩ).
- 분압 저항(20 kΩ)이 RL과 병렬로 걸리므로 펌웨어가 실효 RL을 자동 계산합니다.

## 2. 설치

1. [MicroPython 다운로드 페이지](https://micropython.org/download/RPI_PICO2_W/)에서 **RPI_PICO2_W** 펌웨어(.uf2)를 받습니다.
2. Pico의 BOOTSEL 버튼을 누른 채 USB를 연결 → 나타나는 드라이브에 .uf2를 복사합니다.
3. [Thonny](https://thonny.org)에서 인터프리터를 *MicroPython (Raspberry Pi Pico)* 로 선택하고
   `main.py`, `config.py`, `index.html` 세 파일을 **Pico 루트에 저장**합니다.
4. `config.py`에서 Wi-Fi·센서 설정을 고친 뒤 Pico를 재부팅합니다.

## 3. 접속

| 모드 | 조건 | 접속 방법 |
|---|---|---|
| **AP 모드** (기본) | `WIFI_SSID`가 비어 있거나 접속 실패 | 휴대폰 Wi-Fi에서 `NH3-Pico` (비밀번호 `nh3pico1234`) 연결 → `http://192.168.4.1` |
| **STA 모드** | 학교/집 Wi-Fi 정보 입력 | Thonny 셸에 출력되는 `http://192.168.x.x` 주소로 접속 (같은 Wi-Fi) |

- AP 모드에서는 인터넷 시각을 받을 수 없으므로, **제어 화면을 처음 여는 순간 휴대폰 시각으로 Pico 시계가 자동 설정**됩니다.
  시계를 맞추기 전의 행은 `time` 칸이 비어 있고 `uptime_s`(부팅 후 초)만 기록됩니다.
- 학교 Wi-Fi가 웹 로그인(캡티브 포털)이나 기업 인증(802.1X) 방식이면 STA 모드가 동작하지 않습니다 → AP 모드를 사용하세요.

## 4. 사용 흐름 (수업 예시)

1. 전원 인가 → **예열 3분** (화면에 남은 시간 표시, 해당 행은 `warmup=1`). 새 센서는 24시간 이상 통전(번인) 권장.
2. 환기된 공기에서 **🌬️ 청정공기 교정** → R0 설정, 새 기록 파일 자동 시작.
3. 모둠별로 **＋ 새 기록 시작** (이름: `group1` 등) → 실험 조작 시점마다 **📍 표시** 버튼으로 메모 입력.
4. 실험 후 **⬇ 받기**로 CSV 다운로드 → `nh3.html`에 업로드해 비교·분석.
5. 다운로드가 끝난 파일은 삭제해 공간을 확보합니다 (파일 시스템 수 MB · 5초 간격, 1행 약 70바이트 기준 하루 약 1.2 MB).

USB 연결 시 Thonny의 파일 창(`data/` 폴더)에서 직접 내려받을 수도 있습니다.

## 5. CSV 형식

```
# device=Pico2W-NH3,model=MQ-137,vc=5.000,rl_kohm=10.000,rl_eff_kohm=6.667,div_ratio=0.5000,r0_kohm=20.000,curve_a=39.54,curve_b=-3.802,clean_air_ratio=3.6,calibrated=1,label=group1
time,uptime_s,adc_v,sensor_v,rs_kohm,ratio,ppm,warmup,note
2026-11-12 10:08:00,480,0.9000,1.8000,11.852,0.5926,289.06,0,암모니아수 뚜껑 엶
```

- 계산식: `Rs = RL_eff × (Vc − Vout) / Vout`, `ppm = A × (Rs/R0)^B`
- `#` 머리말에 계산 조건이 들어 있어, 분석 페이지에서 **R0·감도 곡선을 바꿔 ppm을 다시 계산**할 수 있습니다
  (예: 교정을 깜빡한 경우 → "기준선 구간을 청정공기로 간주").

## 6. 측정 원리와 한계 (지도 시 참고)

- n형 SnO₂ 계열 센서: 표면 흡착 산소(O⁻, O₂⁻)가 전자를 붙잡아 공핍층이 형성된 상태에서,
  환원성 기체 NH₃가 흡착 산소와 반응하면 전자가 전도대로 되돌아가 **Rs가 감소**합니다 → Vout 증가.
- **교차 감도**: 에탄올, H₂S, 아민류 등 다른 환원성 기체에도 반응합니다. 손 소독제(알코올) 사용 직후 측정 금지.
- **온·습도 의존성**: 같은 농도라도 습도가 높으면 Rs가 달라집니다. 비교 실험은 같은 장소·시간대에 수행하세요.
- ppm 곡선(A, B)은 데이터시트 그래프를 log-log 직선으로 근사한 값이며 개체 편차가 큽니다.
  정량값보다 **Rs/R0의 상대 변화, 응답·회복 시간** 비교에 활용하는 것이 타당합니다.
- 이 장치는 교육용이며, 작업환경 노출 평가나 안전 판정 용도로 쓸 수 없습니다.

## 7. 안전

- 진한 암모니아수(25~28 %)는 흄후드 또는 환기된 곳에서 교사가 취급하고, 학생 실험은 묽힌 용액을 소량 사용하세요.
- 센서 헤드는 가동 중 50 °C 이상으로 뜨거워집니다. 손으로 만지지 않게 하세요.
- 센서를 액체에 담그거나 용액 표면에 닿게 하지 마세요.
